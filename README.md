# Semantic Segmentation Optimization on Jetson Nano

This repository contains the final report for a Spring 2026 course project in Columbia University E6692.

The project studies hardware-aware optimization of Fast-SCNN for semantic segmentation on NVIDIA Jetson Nano, including pruning, fine-tuning, accuracy evaluation, and inference performance analysis.
